# Lab 02: Agile Backlog Creation & Sprint Simulation in Jira

## Overview

This lab focuses on applying Agile and Scrum practices using Jira. The functional requirements identified in Lab 1 were converted into Epics and User Stories, prioritized, and estimated using Story Points. A sprint was then simulated to track task progress and analyse the team's performance using a Burndown Chart.

## Work Completed

- Created Epics based on the Domain & SSL Certificate Expiry Alert System.
- Created and organized User Stories under the relevant Epics.
- Prioritized backlog items according to their importance.
- Assigned Story Points based on effort, complexity, and uncertainty.
- Created and simulated a sprint in Jira.
- Tracked task progress through the To Do, In Progress, and Done stages.
- Generated Burndown Charts to analyse sprint progress.

## Deliverables

The completed lab submission contains:

1. Screenshots of the available Epics.
2. Jira backlog showing User Stories and Story Points.
3. Active Sprint board.
4. Burndown Charts.
5. Written reflections on estimation, backlog prioritization, sprint execution, and team capacity.
