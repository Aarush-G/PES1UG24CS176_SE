## Lab Details

### Lab 01: Requirements Engineering & UML Use-Case Modelling

This lab focuses on identifying software requirements and representing system functionality through UML use-case modelling.

[View Lab 01](./Lab-01-Requirements-Engineering/)

### Lab 02: Agile Backlog Creation & Sprint Simulation in Jira

This lab applies Agile and Scrum practices using Jira. It includes Epic creation, User Stories, backlog prioritization, Story Point estimation, sprint simulation, Burndown Charts, and written reflections.

[View Lab 02](./Lab-02/)

### Lab 03: Component Modelling & Architectural Pattern Selection

This lab focuses on software component modelling and architectural pattern selection, supported by a component diagram and written justification.

[View Lab 03](./Lab-03-Component-Modelling/)

### Lab 04: Target Aim Trainer

This lab involves debugging and improving a graphical aim trainer developed using Python and Pygame. The implementation covers collision detection, a Game Over screen, replay with difficulty selection, and sound feedback.

[View Lab 04 Repository](https://github.com/Aarush-G/PES1UG24CS176-AimTrainer)

### Lab 05: Static Code Analysis

This lab focuses on improving Python code quality, security, and formatting using Pylint, Bandit, and Flake8. The implementation covers identifying and fixing security vulnerabilities, code-quality issues, and style violations in an e-commerce cart system.

[View Lab 05 Repository](https://github.com/Aarush-G/Lab5_SE_PES1UG24CS176)


## Technologies and Tools

- **Jira** — Agile backlog management and sprint simulation
- **UML** — Requirements and software modelling
- **Python and Pygame** — Interactive game development
- **Git and GitHub** — Version control and repository management
- **Pylint** — Python code-quality analysis
- **Bandit** — Python security analysis
- **Flake8** — Python style and formatting checks
